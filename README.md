# Walmart Sales Forecasting Dashboard

## 📌 Project Overview
This project is a **Power BI dashboard** built to analyze and forecast weekly sales for Walmart retail stores.  
Using historical sales and external factors such as holidays, temperature, fuel prices, CPI, and unemployment rates, the dashboard provides actionable insights for inventory planning and revenue optimization.

---

## 🛠 Tools & Technologies
- **Power BI** (DAX, Power Query, Power BI Service)
- **Python** (Pandas, Matplotlib, Seaborn for EDA)
- **Delta Tables** (Efficient data storage and retrieval)
- **GitHub** (Version control & portfolio hosting)

---

## 📊 Dataset Description
| Column Name      | Description |
|------------------|-------------|
| **Store**        | Store ID number |
| **Date**         | Week ending date |
| **Weekly_Sales** | Total sales for the week |
| **Holiday_Flag** | 1 if the week includes a holiday, 0 otherwise |
| **Temperature**  | Average temperature in the region (°F) |
| **Fuel_Price**   | Average fuel price in the region |
| **CPI**          | Consumer Price Index for the region |
| **Unemployment** | Unemployment rate (%) in the region |

---

## 📈 Dashboard Features
- **Sales Trends Over Time**: Visualizing seasonal peaks and dips in weekly sales.
- **Holiday Impact Analysis**: Comparing average sales during holiday and non-holiday weeks.
- **External Factor Analysis**: Studying how temperature, fuel price, CPI, and unemployment affect sales.
- **Store-wise Performance**: Ranking and filtering stores by revenue.
- **Forecasting**: Predicting future sales using historical trends and DAX forecasting features.

---

## 🚀 How to Use
1. Download the `Walmart project.pbix` file from this repository.
2. Open it in **Power BI Desktop**.
3. (Optional) Connect to the provided sample dataset in `/data` to refresh visualizations.
4. Explore the dashboard by applying filters and slicers.

---

## 💡 Key Insights
- Holiday weeks generally produce **higher sales spikes** compared to non-holiday weeks.
- Certain stores show **consistent top performance**, while others show high variance due to regional factors.
- **Temperature and fuel price fluctuations** have a noticeable correlation with weekly sales trends.
- Forecasting models can guide **inventory and staffing adjustments** ahead of high-demand periods.
